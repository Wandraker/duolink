# Contributing

Pull requests are welcome. Before your first one is merged, please agree to the
[Contributor License Agreement](CLA.md) by adding this line to the PR
description:

> I have read the Duolink CLA and I agree to its terms.

Run `gofmt -w .` and `go vet ./...` before sending.

Правки приветствуются. Перед первым pull request прочитайте [CLA](CLA.md) и
добавьте в описание строку выше.
